# محدودهٔ آزمون انجام‌شده

۴۸ تست خودکار با موفقیت اجرا شدند؛ بدون Skip در محیط ساخت این نسخه:

- ۲۲ تست قبلی بدون تغییر موفق ماندند: ۲۱ تست منطق و ۱ تست یکپارچهٔ OpenCV با مدل Pose ساختگی.
- ۲۳ تست جدید هسته برای ماندن طولانی روی کف: نبود تاریخچهٔ سقوط، آستانهٔ پیش‌فرض و مرز زمانی، تکرارنشدن هشدار، نبود محدودهٔ کف، اولویت تخت، خارج محدوده، نشستن/ایستادن، حرکت روی زمین، وقفهٔ صریح/ضمنی، ابهام وضعیت، حفظ هشدار پس از غیبت، پایان پایدار دوره و مسلح‌شدن مجدد، قطع تأیید پایان، استقلال Trackها، عدم تأخیر سقوط قبلی، نرخ فریم‌های متفاوت، تنظیمات نامعتبر و زمان نامعتبر. چند تست دارای subtest هستند.
- ۳ تست یکپارچهٔ جدید: ویدئوی مصنوعی با OpenCV واقعی و Pose ساختگی؛ ثبت هشدار در CSV و کنسول، ثبت هشدار حل‌نشده هنگام توقف، هشدار غیرفعال‌بودن بدون کف، و حذف Track بدون مختومه‌کردن رخداد.
- کامپایل فایل‌های پایتون، بارگذاری تنظیمات جدید و سازگاری با تنظیمات قبلی بررسی شدند.
- `demo_floor_lying.py` مستقل از YOLO اجرا شد: یک هشدار در ثانیهٔ ۳۰ زمان شبیه‌سازی‌شده، بدون نیاز به مشاهدهٔ افت سریع.

محیط اجرای این تست‌ها: Python 3.13.14، NumPy 2.5.2، OpenCV 5.0.0 از محیط آمادهٔ ساخت. محیط نصب پیشنهادی برای کاربر در requirements.txt/README_FA.md آمده است؛ تطابق بسته‌های آن محیط باید روی دستگاه مقصد بررسی شود.

**انجام نشده:** اجرای YOLO واقعی، دانلود/تست وزن‌ها، تست وب‌کم، RTSP، GPU، ابزار گرافیکی انتخاب محدوده روی نمایشگر، ارزیابی روی سالمندان یا فیلم واقعی و اندازه‌گیری دقت. Ultralytics در محیط ساخت نصب نبود. هیچ ادعای Precision، Recall، حساسیت پزشکی یا دقت درصدی از این تست‌ها قابل استخراج نیست.

## تکرار تست‌ها

از پوشهٔ پروژه:

```bash
python -m unittest discover -s tests -v
python -m compileall -q .
python demo_floor_lying.py
```

در نبود OpenCV، تست مسیر ویدئو Skip می‌شود؛ این به معنی موفق بودن آزمون ویدئو نیست. تست‌های هسته همچنان با NumPy اجرا می‌شوند.

## قبل از کاربرد واقعی

ابتدا اجرای مدل واقعی و پشتیبانی COCO-17، سپس ویدئوهای برچسب‌خوردهٔ محیط خود، سپس تست زنده با رضایت افراد را بررسی کنید. هشدار کاذب و سقوط ازدست‌رفته را جداگانه بسنجید. موفقیت تست‌های مصنوعی شرط کافی برای استقرار مراقبتی نیست.
